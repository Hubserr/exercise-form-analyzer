# Form Analyzer

An Android application for real-time exercisce technique analysis
using MediaPipe Pose Landmarker.

Developed as part of an engineering thesis.

## Code origin
The project is based on the official Google sample
[mediapipe-samples / pose_landmarker / android](https://github.com/google-ai-edge/mediapipe-samples/tree/main/examples/pose_landmarker/android)
(Apache License 2.0). Files originating from the sample retain their original license headers.

## Building
Requires JDK 18.
